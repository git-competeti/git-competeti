# Instruções do repositório

## Entrada obrigatória

- Comece por `.codex/CONTEXT_INDEX.md`.
- Leia `.codex/PROJECT.md` e `.codex/CURRENT.md` antes de editar o perfil.
- Consulte `.codex/SECURITY.md` para conteúdo público e privacidade.
- Consulte `.codex/GIT_WORKFLOW.md` antes de qualquer operação Git.

## Forma de trabalho

- Preserve o propósito deste repositório como perfil público do GitHub.
- Trate todo conteúdo versionado como imediatamente público.
- Valide links, imagens, ortografia, acessibilidade básica e informações profissionais.
- Não publique dados privados, credenciais, documentos pessoais ou métricas não confirmadas.
- Não faça commit, push, alteração de branches ou publicação sem solicitação explícita.
- Evite dependências e automações sem valor claro para um README de perfil.

## Continuidade

- Atualize `.codex/CURRENT.md` para trabalho em andamento.
- Registre decisões editoriais duráveis em `.codex/DECISIONS.md`.
- Mantenha `.codex/MEMORY.md` curta e sem dados sensíveis.
