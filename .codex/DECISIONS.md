# Decisões

## ADR-001 — Contexto operacional versionado

- Status: aceita
- Data: 2026-08-08
- Decisão: usar `AGENTS.md` como entrada curta e `.codex/CONTEXT_INDEX.md` como índice da governança.
- Consequência: regras operacionais ficam fora do README público principal, mas permanecem auditáveis no repositório.

## ADR-002 — Visibilidade pública

- Status: aceita, refletindo o estado existente
- Data: 2026-08-08
- Decisão: manter o repositório público porque ele alimenta o perfil GitHub.
- Consequência: nenhum segredo, documento privado ou dado pessoal desnecessário pode ser versionado.

## Decisão pendente

Definir se o repositório de perfil adotará as três branches padrão ou continuará com `main` apenas. Nenhuma branch será criada automaticamente por este bootstrap.
