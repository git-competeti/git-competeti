# Memória durável

## Fatos estáveis

- Este repositório publica o perfil GitHub da conta `git-competeti`.
- Sua visibilidade é pública por finalidade.
- O conteúdo destaca cloud, infraestrutura, segurança, DevOps, COMPETE TI e automobilismo.
- Qualquer dado versionado deve ser tratado como público.
- Não existe stack executável nem necessidade atual de dependências.

## Uso

Mantenha somente fatos editoriais reutilizáveis. Alterações em andamento pertencem a `CURRENT.md`; decisões sobre posicionamento e fluxo pertencem a `DECISIONS.md`.
